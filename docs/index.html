Java 17 Highlights

Java 17 (LTS) consolidates important language and platform improvements.

  • Pattern matching for instanceof — JEP 394
  • Sealed classes — JEP 409
  • Records — JEP 395
  • Text blocks — JEP 378
  • Pattern matching for switch — JEP 406 (preview in Java 17)
  • Value-based class warnings — JEP 390 (related Java 16 change)
