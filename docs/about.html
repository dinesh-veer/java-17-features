Java 17 Features

This is a hands-on learning project for important Java 17 language and runtime features.

Project Goals

  • Show language changes with runnable code.
  • Compare new and older syntax.
  • Capture tricky compiler and scope rules.
  • Keep each demo focused.

Java 17 and Long-Term Support

Java 17 is an LTS release and a stable baseline for enterprise Java applications.

Feature Categories

  • Language: records, sealed types, text blocks and pattern matching.
  • Control flow: switch expressions and preview pattern switch.
  • Runtime guidance: value-based class warnings.
