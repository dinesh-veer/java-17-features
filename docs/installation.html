Installation & Setup

Set up Java 17, build the repository, and run the demonstrations.

Prerequisites

  • JDK 17
  • Maven 3.8+ recommended
  • Git
  • IntelliJ IDEA, Eclipse or VS Code

1. Install JDK 17

java -version

2. Verify JAVA_HOME

macOS / Linux

echo $JAVA_HOME

Windows

echo %JAVA_HOME%

3. Install Maven

mvn -version

4. Clone the Repository

git clone https://github.com/dinesh-veer/java-17-features.git
cd java-17-features

5. Import the Project

Open the directory as a Maven project and configure JDK 17 as the project SDK.

6. Compile the Project

mvn clean compile

7. Run Tests

mvn test

8. Run an Example

java -cp target/classes com.dinesh.instaceof.InstanceOfExamples
java -cp target/classes com.dinesh.record.RecordExample
java -cp target/classes com.dinesh.textblock.TextBlockExample

9. Preview Features

Pattern matching for switch was preview in Java 17.

javac --enable-preview --release 17 Example.java
java --enable-preview Example

10. Clean Build

mvn clean
mvn compile

Common Problems

  • Preview feature error: enable --enable-preview.
  • Wrong JDK: verify java -version and mvn -version.
  • IDE language level: set it to 17.
  • Value-based warnings: warnings in WarningOnPrimitives are intentional.
