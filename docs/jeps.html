JEP 378 — Text Blocks

Readable multi-line string literals for JSON, HTML and SQL.

JEP 394 — Pattern Matching for instanceof

Pattern variables reduce boilerplate casts and are scoped according to flow analysis.

JEP 395 — Records

Compact data carriers with generated members and canonical construction.

JEP 406 — Pattern Matching for switch

Java 17's first preview adds type patterns, guarded patterns and explicit null handling to switch.

switch (obj) {
    case String s && s.length() > 5 -> "Long";
    case String s -> "Short";
    case Integer i -> "Integer";
    case null -> "Null";
    default -> "Other";
}

JEP 409 — Sealed Classes

Sealed types restrict direct subclasses and make hierarchies explicit.

JEP 390 — Warnings for Value-Based Classes

The repository demonstrates obsolete wrapper constructors and synchronization warnings. JEP 390 was delivered with Java 16, but remains relevant when compiling this Java 17 source.

Related Java 17 Platform JEPs
