Java 17 Feature Overview

This page summarizes the features directly demonstrated by the repository.

Pattern Matching for instanceof

JEP 394 removes the need for a separate cast after a successful type check.

if (value instanceof String s && s.length() > 5) {
    System.out.println(s.toUpperCase());
}

Example: com.dinesh.instaceof.InstanceOfExamples.

Sealed Classes

JEP 409 restricts which classes may directly extend or implement a type.

sealed interface Expr
        permits ConstantExpr, PlusExpr, NegExpr {
    int eval();
}

Records

JEP 395 provides compact data carriers with generated accessors, constructors, equality, hashing and string representation.

record UserInformation(Integer id, String name, Integer age) {
    UserInformation {
        if (age < 0) throw new IllegalArgumentException();
    }
}

Text Blocks

JEP 378 introduces readable multi-line string literals.

String json = """
    {
      "firstName": "Dinesh",
      "lastName": "Veer"
    }
    """;

Switch Expressions

Switch expressions use arrow labels and can return values; the repository also demonstrates yield. JEP 361 was finalized before Java 17.

String result = switch (number) {
    case 1, 2, 3 -> "Low";
    case 10 -> "Exact";
    default -> {
        yield "Other";
    }
};

Pattern Matching for switch (Preview)

JEP 406 was the first preview in Java 17 and is represented by the tricky examples.

switch (obj) {
    case String s && s.length() > 5 -> System.out.println("Long String");
    case String s -> System.out.println("Short String");
    case Integer i -> System.out.println("Integer");
    case null -> System.out.println("Found a null!");
    default -> System.out.println("Unknown type");
}

Value-Based Class Warnings

JEP 390 warns about obsolete wrapper constructors and synchronization on value-based instances.
