Java 17 Examples

Runnable examples mapped to the actual source files in the Java 17 repository.

About the Examples

The source tree contains small, focused classes. The examples below map concepts to actual files.

Pattern Matching for instanceof

com.dinesh.instaceof.InstanceOfExamples covers pattern variables and guarded conditions.

if (obj instanceof String s && s.length() > 5) {
    result = s.contains("JDK");
}

Switch Expressions

DayofWeekExample compares old syntax with switch expressions; SwitchExamples demonstrates yield.

Records

com.dinesh.record.RecordExample shows compact-constructor validation. The tricky examples cover shallow immutability, interfaces, static fields and serialization.

Sealed Classes

SealedInterfaceExample, SealednSubclassInSameClass and RecordAsSubClass demonstrate permitted hierarchies and records as subclasses.

Text Blocks

com.dinesh.textblock.TextBlockExample compares escaped strings with HTML, JSON and SQL text blocks.

Tricky Pattern Matching Cases

PatternMatching and PatternMatching_2 illustrate scope, negated patterns, ternary expressions and effectively proven flow.

Pattern Matching for switch and null

PatternWithNull explicitly handles null and guarded type patterns. These examples use the Java 17 preview syntax.

Value-Based Classes

WarningOnPrimitives demonstrates wrapper constructor and synchronization warnings associated with JEP 390.
